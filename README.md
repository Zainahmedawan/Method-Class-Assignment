# Method Class Assignment

## Description
This console application demonstrates:

- Creating a class
- Creating a void method with two integer parameters
- Performing a math operation on the first parameter
- Displaying the second parameter
- Calling a method using positional arguments
- Calling a method using named arguments

## Requirements Completed

- Created a class named MathOperations
- Created a void method named PerformOperation
- Method accepts two integers
- Performs a math operation on the first integer
- Displays the second integer
- Instantiated the class in Main()
- Called the method with regular parameters
- Called the method with named parameters
- Added comments throughout the code
